# National benchmarks

`national_benchmarks.csv` is copied from Project 02
(`https://github.com/JonathanDoanePhD/mathematics-of-mentorship/blob/main/output/benchmarks/national_benchmarks.csv`, built by
`scripts/05_national_benchmarks.py`) so this project can run on its own. Rebuild it there and
copy it again to refresh.

- NSCH 2024: parent report, ages 12-17, weighted; split by family income (< 200% vs 200%+ of
  the federal poverty line).
- YRBS 2023: student report, grades 9-12, weighted; split by whether an adult reliably made
  sure basic needs were met.
- Confidence intervals use a Kish effective sample size (weights only), so design-based
  intervals would be somewhat wider.

These are **descriptive context, not a comparison group**: different populations, years and,
for NSCH, a different respondent (parent vs. youth). Verify against the original sources
before quoting.
