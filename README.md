# 03 - Mentorship Impact Engine

**Question:** How would a mentoring program built on Project 02's "bridging adults" model know
whether it works, for whom, and how sure it can be?

**Status:** complete as a working prototype (2026-11-13) on **synthetic data**: evaluation
plan, item bank with national benchmarks, data schema with privacy rules, simulator,
analysis pipeline, power analysis and dashboard. Next step in the real world: pilot the
survey with a small group of youth (wording, length, reading level) and settle the
comparison design with a partner.

> **No real participant data lives here.** Everything in `data/synthetic/` and `output/` is
> generated by `engine/simulate.py`. Real exports stay outside the repository (see
> [docs/data_schema.md](docs/data_schema.md)). People, not this engine, make decisions about
> participants.

## Run it

```bash
pip install -r requirements.txt
python3 -I scripts/run_pipeline.py                 # synthetic demo (about 5 seconds)
python3 -I scripts/run_pipeline.py --data /secure/export   # a real program's export
```

Outputs: `output/results/*.csv` (every table behind the dashboard), `output/results/results.json`,
`output/power/power_grid.csv`, `output/dashboard.html`.

## Design choices, and what building it taught us

1. **Items reused from national surveys come with free benchmarks.** About a third of the
   items reuse NSCH or YRBS wording, so a program can show "our youth at intake vs. teens
   nationally". The other items are original, so there are no licensing questions. Validated
   proprietary scales (e.g., relationship-quality inventories) are listed as alternatives to
   check.
2. **Measured effects come out smaller than "true" effects.** The simulator builds in
   0.20-0.25 SD gains for a full-length, average-quality match. The analysis recovers about
   **0.07-0.16 SD**, because comparing everyone assigned (including the 29% of matches that
   end early) dilutes the effect, and survey measurement error dilutes it again. Programs
   should plan, and tell funders, around effects of about 0.1-0.15 SD, not the 0.2+ in
   headlines.
3. **So sample size matters more than most programs expect.** About **400 youth per group**
   gives 80% power for a 0.2 SD effect at this program's attrition; 0.1 SD needs more than
   600 per group. Smaller programs should pool cohorts, or lean on goal attainment and
   description instead of impact claims.
4. **Retention is the biggest threat.** In the demo, 84% of program youth but only 70% of
   comparison youth answer at 12 months, a gap large enough to be flagged. Budget for
   follow-up with comparison youth (incentives, surveying during school).
5. **Early closures matter.** Youth whose matches ended early showed no gain (and a slight
   drop in belonging), consistent with mentoring research. The 3-month relationship check is
   built in as an early-warning flag for staff, not an automated decision.
6. **Two-item scales are fragile.** "Supportive adults" and "Bridging ties" mix answer formats
   and fall below alpha 0.70. The dashboard flags this automatically; with real data, report
   those items separately or expand the scales.
7. **Hope is a secondary outcome on purpose.** Project 02 found emotional outcomes respond
   least under hardship, so the plan does not promise wellbeing gains from mentoring alone,
   and sensitive items (HO2, CX1) come with a safeguarding requirement.

## Caveats

- The simulator's assumptions come from published averages and Project 02's associations; a
  real program's numbers will differ. Calibrate the power analysis with pilot data.
- National benchmarks are context, not a comparison group.
- Effect sizes and citations need checking against original sources before funder use.

## Cross-check with Project 08 (2026-11-19)

Project 08's evidence map supports planning for small effects:
- Academic effects stated in abstracts pool to about d = 0.27 (randomized median 0.22).
- The one pooled school-mentoring meta-analysis in the set reports g = 0.09.
- Only 56% of findings in rigor 4-5 studies are positive.
